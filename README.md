## 二、設計動機與目標

希望將讀書計時與虛擬寵物養成結合，讓專注不只是倒數計時，而是可以獲得金幣、經驗值、照顧寵物的正向回饋。使用者可自由選擇專注夥伴，並透過讀書任務與專注紀錄掌握自己的學習情況。

## 三、網站介面截圖與操作說明

1. **寵物角色切換**：可選擇小貓、兔子或小熊作為專注夥伴，切換角色時保留原有養成進度。
2. **番茄鐘專注計時**：選擇專注時長後開始倒數，支援暫停與重設；完成專注可獲得金幣與經驗值。
3. **自由專注計時**：使用正計時方式記錄讀書或工作時間，可暫停、繼續及結算，完成後納入專注紀錄。
4. **每日任務管理**：新增今日學習任務，並勾選完成項目，方便掌握讀書進度。
5. **寵物養成與商店**：透過餵食、玩耍及休息照顧寵物，使用專注累積的金幣購買食物並提升等級。
6. **專注紀錄與資料保存**：查看累積專注時間與完成紀錄；使用 `localStorage` 保存寵物、任務與學習進度。

**操作流程：** 選擇寵物 → 新增任務 → 開始番茄鐘或自由計時 → 完成專注獲得獎勵 → 照顧寵物並查看紀錄。

## 四、功能規格書

| 功能 | 規格說明 |
|---|---|
| 寵物角色切換 | 提供小貓、兔兔、小熊三種角色，切換後保留目前養成進度。 |
| 寵物互動 | 餵食、玩耍、休息；影響飽足感、心情、活力。 |
| 番茄鐘 | 可選 1、15、25、45 分鐘；支援開始、暫停、繼續、重設；完成後給予獎勵。 |
| 自由專注正計時 | 由 `00:00:00` 開始累積，支援暫停、繼續、結束紀錄與清零；至少 1 分鐘才可結算。 |
| 任務管理 | 新增、勾選完成與刪除每日讀書任務，顯示完成數量。 |
| 養成與升級 | 專注及互動可取得 XP；升級後顯示等級與成長狀態。 |
| 金幣與商店 | 使用專注獎勵購買胡蘿蔔、草莓、小蛋糕，存入背包供餵食使用。 |
| 專注紀錄 | 顯示完成次數、今日專注分鐘、累計分鐘與最近紀錄。 |
| 本機儲存 | 透過 `localStorage` 保存寵物、任務、金幣與專注歷史。 |

## 五、使用者操作流程

1. 開啟網站並選擇喜歡的寵物角色，可自行命名。
2. 新增今日讀書任務，選擇番茄鐘或自由正計時。
3. 完成專注後取得金幣與 XP，並查看專注紀錄。
4. 使用金幣購買食物，餵食或陪伴寵物成長。
5. 下次開啟同一瀏覽器時，讀取先前保存的進度。

## 六、技術規格

前端使用 HTML5、CSS3 與原生 JavaScript；以 SVG 呈現寵物圖像，使用 `localStorage` 保存資料。無需伺服器、資料庫或 API Key。以單一 `index.html` 發布，符合 GitHub Pages 的靜態部署方式。
